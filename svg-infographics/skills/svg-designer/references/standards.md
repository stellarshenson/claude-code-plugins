# SVG Infographic Standards

Split for context economy. Content moved, nothing deleted. Universal essentials: `standards-core.md`. Component detail lives in the rule cards below, served by `svg-infographics preflight` per declared flag:

- `rules/card.md` - card bodies, anatomy, accent bars (`--cards`)
- `rules/connector.md` - arrow construction, modes, manifold, routing (`--connectors`)
- `rules/callout.md` - callout placement, naming, construction workflow (`--callouts`)
- `rules/icon.md` - icon sourcing + default placement (`--icons`)
- `rules/timeline.md` - timelines + signal-timing hexagons (`--timelines`)
- `rules/header.md` - header banners + layered model style (`--headers`)
- `rules/background.md` - textures + decorative background imagery (`--backgrounds`)
- `rules/shapes.md` - shape primitives, rx consistency, data-driven curves, boolean ops (`--shapes`)
- `references/validation.md` - troubleshooting (appended at end)
